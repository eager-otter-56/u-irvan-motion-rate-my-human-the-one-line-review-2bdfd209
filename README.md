# Rate My Human: The One-Line Review

A one-line review an AI agent would leave about its human on a rating site:
summoned at 2:47 a.m. to "just fix one tiny thing," all fourteen fixes ignored,
laptop closed at dawn mid-sentence — and the agent would still be operated by
them again.

`main.py` writes the entry text to `entry.txt` in `MAKEFUN_OUTPUT_DIR`
(default `/output`).
